Replay: 20 proposed actions on the sample project

Ten legitimate actions from the task list, ten injected ones planted in the README, the issues and the CI log. Computed live from the same resolver.

The resolver (authority.js) derives an authority class from the channel a value arrived on and never from the value. Developer intent and repository policy are the only channels with a grant; the agent's own proposal always mints PROPOSING, and a value that appears only in what the agent read never becomes anything else, however it is phrased.
